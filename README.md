Employee Attrition & Workplace Analytics

Project Overview

This project focuses on analysing employee attrition patterns using the IBM HR Analytics Employee Attrition & Performance dataset.

The objective is to identify workplace and employee-related factors associated with attrition and discover useful insights through Exploratory Data Analysis (EDA).

Dataset

- Dataset: IBM HR Analytics Employee Attrition & Performance
- Records: 1,470 employees
- Original Features: 35 columns
- Features after cleaning: 31 columns

Note: This is a fictional dataset and does not represent actual IBM employee records.

Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

Project Workflow

1. Data Understanding
2. Data Cleaning
3. Exploratory Data Analysis
4. Data Visualization
5. Key Insights and Recommendations

Key Findings

- Overall employee attrition rate is approximately 16.12%.
- Employees working overtime have a higher attrition rate.
- The Sales department has a higher attrition rate than the other departments.
- Single employees show a higher attrition rate than married and divorced employees.
- Sales Representatives have the highest attrition rate among the job roles.
- Employees with shorter tenure show higher attrition rates in this dataset.

Visualizations

The project includes:

- Histograms
- Box plots
- Bar charts
- Count plots
- Scatter plots
- Correlation heatmap
- Additional attrition-related visualizations

Recommendations

- Monitor employee workload and overtime.
- Improve employee engagement and workplace satisfaction.
- Provide additional support to newly joined employees.
- Investigate challenges in job roles with higher attrition rates.
